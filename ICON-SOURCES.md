# Logo and symbol sources

## Corrected project-hosted artwork

The following four replacements use the original images served by their official
project or vendor repositories, without redrawing or recoloring them:

- **JAX**: https://raw.githubusercontent.com/jax-ml/jax/main/images/jax_logo_250px.png
  Referenced by the JAX project README: https://github.com/jax-ml/jax
- **NumPyro**: https://raw.githubusercontent.com/pyro-ppl/numpyro/master/docs/source/_static/img/pyro_logo.png
  This is the red/orange/yellow mark explicitly identified as the NumPyro logo in
  the project's README, not the previous representative flame.
- **MATLAB**: https://raw.githubusercontent.com/mathworks/MATLAB-extension-for-vscode/main/public/L-Membrane_RGB_128x128.png
  This is the product icon specified by MathWorks in the official extension's
  package.json: https://github.com/mathworks/MATLAB-extension-for-vscode
- **vLLM**: the official yellow/blue wordmark, with original dark- and light-theme
  variants, as used by the vLLM README:
  https://raw.githubusercontent.com/vllm-project/vllm/main/docs/assets/logos/vllm-logo-text-light.png
  https://raw.githubusercontent.com/vllm-project/vllm/main/docs/assets/logos/vllm-logo-text-dark.png

These four images are referenced directly over HTTPS. They are not bundled in the
ZIP, and require an internet connection. Their image URLs were checked when this
revision was prepared. All other profile graphics are local. The older replacement
artwork for these four brands has been removed from this kit.

## Retained local artwork

Python, PyTorch, Hugging Face, TensorFlow, scikit-learn, NumPy, Pandas, Linux,
GNU Bash, Docker, Google Cloud, Git, C++, C, R, PostgreSQL, and MySQL retain the
Simple Icons-derived outlines from the preceding kit. Some are recolored.
Project and license: https://github.com/simple-icons/simple-icons
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Matplotlib retains the SVG from the Matplotlib distribution:
https://github.com/matplotlib/matplotlib

The verl mark retains the geometry of its public organization avatar:
https://github.com/verl-project.png

Seaborn retains the earlier simplified mark. Slurm/HPC and SQL retain representative
cluster and database symbols; the combined Bash/Zsh entry uses the Bash mark.
These retained symbols are not claimed to be newly verified official artwork.

## Presentation

The five category headings remain. Each linked logo now has a small, centered,
visible name beneath it. FSDP is removed; LaTeX remains excluded. Captions are HTML
text in README.md, not part of a flattened screenshot. Native ruby/rt/sub markup
keeps the caption attached to its logo without a custom stylesheet or bordered
cards. Widths are allowed to vary to preserve wide wordmarks.

All names and marks identify the relevant software; no endorsement is implied.
No font files are included.
